# Security Policy

## Supported Versions
We provide security updates for the latest major version of Flustro. Please ensure you are running the latest version available on the [Releases page](../../releases/latest).

## Reporting a Vulnerability
If you discover a security vulnerability in Flustro, please **do not** report it by creating a public GitHub issue. 

Instead, please email the developer directly. We will acknowledge your report within 48 hours and work with you to resolve the issue before public disclosure.
