# Contributing to Flustro

Thank you for your interest in contributing to Flustro! 

As a reminder, **the core source code for Flustro is private**. This repository is strictly for distributing releases and tracking public issues. 

However, you can still contribute to the project in very meaningful ways:

## 1. Reporting Bugs
If you find a bug, please use the **Bug Report** issue template. Include as much detail as possible: your Operating System (e.g., Linux Wayland, macOS Sonoma), the Flustro version, and exact steps to reproduce the issue.

## 2. Suggesting Features
Have an idea for a new feature? We'd love to hear it! Use the **Feature Request** issue template or start a discussion in the [Discussions tab](../../discussions).

## 3. Helping Others
If you see another user asking for help in the Issues or Discussions tabs, feel free to jump in and share your knowledge! Workarounds and OS-specific tips are incredibly valuable.
