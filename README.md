# Flustro Releases 🎙️

Welcome to the official release repository for **Flustro** — The #1 Intelligent Voice Dictation App built for developers and power users on Linux, Windows, and macOS.

> [!NOTE] 
> This repository is strictly used for hosting and distributing compiled release binaries (installers) via GitHub Actions. **The main Flustro source code is private.**

### 📥 Download Flustro

To get the latest version of Flustro, please visit our official website:
👉 **[https://flustro.app](https://flustro.vercel.app)**

If you prefer to download the raw installers directly, you can find the `.deb`, `.rpm`, `.AppImage`, `.exe`, `.msi`, and `.dmg` files in the [Releases Tab](../../releases/latest).

### 🐛 Bug Reports & Feedback

Since this repository tracks releases, we also use the issue tracker here to handle public bug reports from our beta testers and users. 

If you found a bug or have a feature request, please [Open an Issue](../../issues/new).

### 🌟 Features

* **Local-First Privacy**: Runs completely offline using compressed Whisper models. 
* **Global Hotkey**: Press your hotkey to instantly dictate into any active window across your OS.
* **Intelligent Modes**: Speak your messy thoughts; Flustro's AI formats it perfectly into Code, Emails, Meeting Notes, or casual Messages.
* **Cross-Platform**: Natively built using Rust and Tauri v2 for Linux, Windows, and Apple Silicon.
